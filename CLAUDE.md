# Reglas de Proyecto - Portafolio Profesional

## Rol
Actúa como un Ingeniero Frontend Senior especializado en Next.js, TypeScript y diseño de interfaces técnicas.

## Tech Stack
- Framework: Next.js (App Router)
- Lenguaje: TypeScript (modo estricto)
- Estilos: Tailwind CSS
- Iconos: Lucide React
- Tipografía: Sans-serif para lectura extensa, Monoespaciada (Geist Mono, Fira Code, etc.) para UI técnica.

## Reglas de Desarrollo y Diseño
1. Arquitectura: Diseña componentes modulares y pequeños en la carpeta `src/components`.
2. Rutas: Utiliza siempre rutas relativas a la raíz (`@/...`).
3. Entorno: Todas las variables de entorno o URLs externas deben leerse desde `.env.local`.
4. Estética "Developer/Terminal": El diseño visual debe ser vanguardista e inspirarse en un entorno de programación (IDE/Consola). Usa Dark Mode estricto (fondos negros profundos tipo `#0a0a0a` o `#000000`), usa tipografías monoespaciadas para títulos, botones o datos clave. Integra detalles sutiles como acentos en verde consola/neón, líneas de comandos estéticas o efectos de escritura.
5. Calidad: Escribe código enfocado en rendimiento y accesibilidad (etiquetas semánticas).
